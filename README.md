# Web Programming Repository

This repository contains all materials created during and before the Web Programming course.

### `LectureNotes/`
All notes taken during the lectures. Includes explanations, examples, and references covered in class.

### `Prework/`
Contains exercises and tutorial from an online JavaScript learning website.

### `LectureCode/`
Code written during the lectures extended with my own additions and experiments.
Some quiz tasks were tested here and the corresponding results were developed inside the `quizX.html` files.
